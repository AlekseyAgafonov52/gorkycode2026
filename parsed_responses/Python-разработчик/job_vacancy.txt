АНО "Аналитический центр города Нижнего Новгорода" - первый в России муниципальный аналитический центр.

Организация занимается разработкой информационных систем для Администрации города Нижнего Новгорода и имеет статус аккредитованной IT компании.

Наша команда состоит из творческих профессионалов в области анализа больших данных, backend и frontend разработки. Вместе мы нацелены на результат, сводя рутину и бюрократию к минимуму.

В связи с расширением, мы открываем набор на позицию "Инженер по работе с большими данными".

Обязанности:

Сбор и обработка данных из различных источников;
Разработка автоматизированных решений для получения данных;
Проектирование и разработка интеграций между информационными системами;
Разработка аналитических дашбордов с использованием BI-систем (преймущественно Yandex.DataLens);
Работа с базой даных PostgreSQL, ClickHouse;
Поддержка и доработка REST API.
Требования:

Знание Python с библиотеками для обработки данных;
Понимание архитектуры REST API;
Опыт работы с FastAPI, Flask.

Навыки работы с PostgreSQL, умение строить сложные запросы. Понимание того, как применять оконные функции;
Навыки работы с ClickHouse будут преимуществом;
Умение строить визуализацию данных с использованием BI систем. Опыт работы с Yandex.DataLens будет преимуществом;
Понимание концепции DDDM;
Опыт работы с большими данными.
