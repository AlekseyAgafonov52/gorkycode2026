# Фронт-прототип для HR

Чтобы HR могли посмотреть общую картину: вкладки вакансий, карточки откликов со светофором, по клику — PDF-отчёт и две кнопки.

Без сборки и библиотек. Данные берутся из файлов отчётов `otchet_offline/hr_report.py` (`ranking.json` и `report-N.pdf`).

## Запуск

Из корня репозитория:

```powershell
python -m http.server 8080
```

Открыть http://localhost:8080/frontend/

## Где менять источники

`config.js` — список вакансий: путь к `ranking.json` и (необязательно) папка с JSON откликов. Новая вакансия — новая строка, PDF должны лежать рядом с её `ranking.json`.

## Что пока заглушка

- ФИО в откликах нет, на карточке номер отклика и должность из резюме.
- Кнопки «Созвонились…» сохраняют отметку только в браузере (localStorage). Потом их надо повесить на `PATCH /api/v1/responses/{id}/status`.
